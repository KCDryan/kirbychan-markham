# Logo

| File | Where it shows |
| --- | --- |
| `logo.svg` or `logo.png` | Header, on the light background |
| `logo-light.svg` or `logo-light.png` | Footer, on the dark background. Falls back to `logo` if missing |

Currently the Kirby Chan & Co. mark from kirbychanandco.com, recoloured to the Markham palette:
evergreen panel with ink text for the header, brass panel with light text for the footer.

SVG is best if you ever get vector files. Until a file exists the text wordmark is shown.
